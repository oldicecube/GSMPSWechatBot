# 暂停主动 LLM 回复

`chat.reply_timing.reply_only_when_at=true` 将 QQ / 微信的 LLM 回复限制为本批新收到且未过期的真实 @。昵称提及、插件 force_reply、普通接话、定时主动任务、子代理完成唤醒及没有新 @ 的 wait 超时不能获得回复授权。授权限于当前轮次，不从历史消息或另一个群继承；模式启用时不进入共享 Focus，自身上下文仍正常接收。Replyer 入口和生成后发送边界再次检查。

本机同时设置 `mentioned_bot_reply=false`、`private_reply_paused=true`；`inevitable_at_reply=true` 保留。普通插件、命令、拍一拍等非 LLM 路由不受此开关影响。当前自主生活、热点环境分享、生活日程分享及自动 B 站搬运配置已关闭，本次未更改其配置。

WebUI 麦麦设置的回复时机区域提供「仅被 @ 时回复」开关，复用已有 schema 表单。恢复原策略时关闭此开关；如需恢复本次暂停前的私聊及名字提及行为，再将私聊暂停关闭、提及必回复打开。原 `talk_value=0.1` 未改动。现有不响应时段仍优先于 @ 回复。

本次检查时主 bot 未运行，没有手动启动或重启。源码和本机配置在下一次用户启动时生效，后续开关可随原生配置热更新。只提交实现和隔离测试，不提交运行配置。

验证：`scripts/at_only_reply_acceptance.py` 覆盖两端、旧 @ 隔离、名字提及 / 插件强制绕过拒绝、私聊主动任务拒绝、共享 Focus 隔离、Planner 入口静默、@ 授权与轮次清理、Replyer 入口拒绝及配置恢复；原不响应时段的 6 项回归通过。无真实 LLM 请求、群消息或禁言操作。
