# QQ 拍一拍递增禁言与群聊风格学习调整

## QQ patpat

`auto/patpat.py` 现在按“QQ 群 + 发起人 QQ 号”持久化拍一拍累计次数：

- 第 1、2 次必定不禁言。
- 第 3 次只有配置概率触发，默认 60%，触发时固定 60 秒。
- 第 4 次起，默认至少约 75% 触发，随机时长使用偏向短时长的分布；累计次数仍会逐步提高时长上限。
- 默认累计到第 10 次必定触发，随机 1800–3600 秒（30–60 分钟）。
- 最高时长硬限制 3600 秒；成功禁言后该用户在该群的计数归零，QQ mute 工具失败则保留累计次数。

计数保存在 `data/bot.sqlite3` 的 `json_documents`（文档名 `data/patpat_state.json`）中。QQ mute 通过原生 MaiBot 工具调用，沿用管理员、群白名单、保护名单和平台权限检查；拍一拍没有普通消息 ID 时，直接使用适配器验证的发起人 QQ 号，不再因为缺少消息 ID 失败。没有新建第二个 QQ 连接。非 QQ 拍一拍仍保持原有“拍你吗”回复。

WebUI 可配置：是否启用、第三次概率、强制累计次数、最长时长。测试使用拦截工具，未执行真实禁言。

## 群聊风格与养成状态

近期生产数据（只读）显示：

- 总消息 3766；QQ 指定群 282 条，时间跨度约 2026-10-30 20:55 至 2026-10-31 01:59，实际只积累了几个小时的 QQ 群样本。
- 表达方式 545 条，其中 382 条出现次数大于 1、163 条只有一次；最高计数 72。
- 黑话 214 条，其中 171 条只出现一次、43 条多次出现；当前很多 AI 黑话条目的含义仍为空，只有少量被判为 `is_jargon`。
- 人物画像 74 条，工具记录 551 条；自主生活事件 56 条，主动分享仍为 0，两个自主项目处于 active。

因此“养得太短”确实是参与热情和抽象风格不稳定的主要原因之一：样本量不算少，但 QQ 群的真实连续观察时间很短，很多学习条目还没有第二轮语境复核。现有表达库数量较多，却有明显的“一次性候选膨胀”和黑话含义未完成问题，不能把数量直接当成熟度。

本轮已调整：

- 黑话含义复核阈值从 4/8/25/100 降为 2/4/12/40 次，较早吸收“绷不住了”“典”这类高频语境词。
- 学习提示明确优先高频、非标准、需要群聊文化理解的词；允许学习粗口、脏话、阴阳和夸张表达的群内用法，同时跳过“好困啊”“我来了”“好的”等字面明确的普通口语。
- 回复提示在玩梗、荒诞前提、互相调侃时允许一次短的误解、身份反转或情绪升级，并鼓励匹配学习到的表达；事实、命令、技术和严肃话题仍保持克制。
- `config/bot_config.toml` 的行为准则补充了“可从无关对话自然插入反应/联想/吐槽”和“每轮最多抓一个荒诞钩子”，避免把 bot 变成只等 @ 的客服。
