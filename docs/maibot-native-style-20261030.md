# 麦麦原生行为与表达风格复核

## 对比结论

以当前源码 MaiCore 1.3.15 为准，原生 `PersonalityConfig` 的说话要求就是“平淡简短”、参考贴吧、表达随意、不滥用比喻；原生群聊要求简短、日常、不浮夸、读空气，不必回复每个人，也不要没话题硬找话题。当前群聊/私聊注意事项和参与时机配置与原生默认一致，没有发现另外配置的冷淡模式。不能把完全还原原生风格等同于持续热情或高频接话。

发现适配缺失：`native_prompt_policy.native_styles()` 为保留自定义身份，之前从原生行为准则中删除整段原生人格；这也误删了末句“善于用人类的角度思考问题，聊天比较日常。”。原生人格前两句涉及身份与性格，按用户要求继续不覆盖自定义设定；末句属于日常交流准则，应保留。

另一个关键点是原生 Planner 读取 `behavior_style`，Replyer 读取 `personality` 与 `reply_style`，不会读取 `behavior_style`。因此仅补 Planner 字段不够。

## 本次修改

- `llm/core/native_prompt_policy.py`：从当前源码的原生人格中提取上述日常交流句，保留到 Planner 行为准则与 Replyer 说话准则。实际两个阶段各出现一次。继续继承原生其余风格和群聊/私聊要求，不引入自创热场指令。
- `llm/core/maibot_native_config.py`：原生风格策略同时同步原生备用风格数组与触发概率，防止以后启动时旧的备用风格覆盖原生配置。当前触发概率原本就是原生的 0，实际未增加随机短回复。
- `config/bot_config.toml`：应用上述原生日常交流句。保留自定义人格全文、身份、性格与 11 条行为边界；人格文本 SHA256 修改前后均为 `776ab6c455f16a2fa560c93ffa25187e7a874d345b3291b317764ca152a01d2f`。
- `scripts/maibot_style_acceptance.py`：独立实例中的启动映射回归和实际原生提示词构造验收，可选虚构聊天模型采样。

未修改 MaiBot 原生提示词模板或原生默认配置类；没有调整模型优先级、群聊参与频率、自主生活限额或注意力漂移实验开关。自主生活插件仍是主动行为的统一入口，其他主动调度插件保持原有关闭状态。
