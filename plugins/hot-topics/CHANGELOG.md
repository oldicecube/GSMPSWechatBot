# 更新日志

所有日期为本地时间（UTC+8）。插件 ID：`zhaocang.hot-topics`

## 0.7.4 — 2026-09-08

- 新增「主动提起优先级」配置（low / normal / high，默认 low）——low 太容易被 Planner 以“气氛不合适”否决，想让她更容易主动开口可改 normal
- 主动提起成功时写入日志「主动提起已写入意图（群 x，优先级 y）」，便于排查
- 文案：主动提起提示同步为多群逻辑，界面文案全中文复核

## 0.7.3 — 2026-09-08

- 主动提起支持覆盖**所有群**或**随机 N 个群**（新增「主动提起群数」，0=全部）
- 主动提起成功日志补全（此前只记录失败，成功无痕迹）

## 0.7.2 — 2026-09-08

- **修复**：主动提起的概率门控自 0.6.4 起未生效（未命中分支没包住后续逻辑，实际 100% 触发）
- **修复**：主动提起只取列表第一个群（`[:1]`），填多个群时其余不生效——改为随机挑选

## 0.7.1 — 2026-09-08

- 防止回复泄漏工具名：工具描述增加约束 + 返回素材末尾附加转述提示
  （此前偶发回复中出现「【工具调用】get_hot_topics」字样）

## 0.7.0 — 2026-09-06

- 新增「全局生效模式」：开启后无需填群号/私聊号，自动应用到所有聊天流
  （基于 `chat.get_all_streams`；聊天内容定制与黑名单在全局模式下仍按 ID 生效）

## 0.6.6 — 2026-09-06

- 新增「聊天黑名单」：按群/私聊屏蔽含指定关键词的内容（与全局雷区叠加）

## 0.6.5 — 2026-09-06

- 全局白名单补全：严格模式此前漏覆盖随机漫步的热榜采样，现三路（热榜/漫步/订阅）统一
- 字段更名「全局白名单（只收兴趣命中）」，语义更直白

## 0.6.4 — 2026-09-05

- 新增「主动提起概率」：刷到了也不一定说，按概率决定要不要尝试开话题

## 0.6.3 — 2026-09-05

- 内容定制扩展到私聊：`群号或QQ号:关键词` 通用

## 0.6.2 — 2026-09-05

- 新增「聊天内容定制」：按群配置白名单关键词，只注入命中的内容

## 0.6.1 — 2026-09-05

- 新增「表达约束」：自定义她聊热点话题时的表达方式（软约束，附加到注入与主动提起）

## 0.6.0 — 2026-09-05

- 上架前全面体检：manifest v2 字段、能力声明与实际使用一一对应、安全自查（无凭据泄露、无 SSRF 面、数据目录规范）
- 修复主动触发重复调用（每次刷到唤醒 Planner 两次）
- 主动提起改为直接填群号（自动解析，不再需要查内部 stream_id）

## 0.5.6 — 2026-09-05

- 精简配置：移除「直接推送」「注入聊天流 ID（进阶）」两个用不到的字段

## 0.5.5 — 2026-09-05

- 支持私聊：填对方 QQ 号即可把“刷到”注入私聊（需已有会话）

## 0.5.4 — 2026-09-05

- 注入文案增加时间标注（例：9月05日 11:54 你在搜索刷到了…）
- 订阅搜索结果过滤模型开场白与 markdown 符号，素材更干净

## 0.5.3 — 2026-09-05

- 过滤全局化：雷区 / 兴趣 / 严格模式此前只作用于热榜工具线，现覆盖随机漫步与订阅搜索三条路径

## 0.5.2 — 2026-09-05

- 采样池平台支持中文填写（B站 / 抖音 / 微博…，大小写与拼音均可）
- 配置文案修正：密钥字段去掉误导性“选填”、API 实例地址补充来源说明
- 清理跨目录读取重构后的遗留字段

## 0.5.1 — 2026-09-05

- 新增「新鲜度阈值」：按日期自动过滤超龄内容

## 0.5.0 — 2026-09-05

- **移除 RSSHub 依赖**，改为「订阅查询词」：定期全网搜索关注的话题（零部署、需 DeepSeek 密钥、选填）
- 关注话题而非账号，覆盖 B站/抖音/贴吧/新闻站等全平台
