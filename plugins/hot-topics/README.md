# 热点雷达 · 圈子资讯订阅感知

让 MaiBot 像真人一样"泡在信息流里"：全网热榜、圈子动态、随机"刷到"，
三路信息经雷区过滤、人设兴趣加权和新鲜度校验后，作为素材交给角色
用自己的口吻自然聊起——看到圈内新闻会好奇，看到角色调整会想吐槽，
而不是播报新闻。

## ✨ 功能全景

- **热榜工具**：`get_hot_topics`，Planner 在聊到时效性话题时自主调用
  （微博/知乎/抖音/B站/贴吧等 11 个源可选，默认开 B站+抖音）
- **雷区过滤**：最高优先级、**全局生效**（热榜/漫步/订阅三条路都拦），
  用户可自由增删关键词。⚠️ 注意：这是**关键词字面匹配**（标题+摘要），
  **无法保证 100% 拦截**——变体、谐音、未出现关键词的内容会漏网；
  如需语义级过滤，请搭配「表达约束」软引导，或等待后续版本的内容分类能力
- **人设兴趣加权**：配置兴趣关键词，命中的话题置顶标注；也可开
  「严格模式」只保留命中内容
- **随机漫步**：后台低频"刷到"非头条内容，静默注入会话上下文——
  之后聊到相关话题能自然想起"我之前刷到过"（支持 random / LLM 按人设筛选）
- **订阅查询词**：关注的是话题而不是账号——定期全网搜索关注的话题，
  不上热搜的圈子动态也能刷到（需 DeepSeek 密钥，选填）
- **聊天内容定制**：按群或私聊配置关键词，每个聊天只注入命中的内容——
  游戏群只收游戏资讯，二次元群只收二次元动态
- **表达约束**：自定义她聊热点话题时的表达方式（如保持客观友善、吐槽点到为止）
- **新鲜度校验**：搜索结果按日期自动过滤超龄内容，只"刷到"新鲜事
- **主动提起**（可选）：刷到内容后写入意图唤醒 Planner，是否开口由角色自己决定

## 🚀 快速开始

1. 安装插件后**无需任何部署**，重启 MaiBot 即可用
2. WebUI → 插件设置 → 填写「人设兴趣关键词」（你的角色会关心什么）
3. 按需开关信息源（默认仅 B站热搜 + 抖音热点）
4. 可选：开启「随机漫步」并填入 QQ 群号，让角色拥有"刷到"的记忆

数据来自开源项目 [60s API](https://github.com/vikiboss/60s)，插件内置
多实例自动切换，无密钥、零第三方依赖（纯标准库实现），
本地部署与云端部署行为一致。

## 📡 进阶：订阅查询词（可选）

角色关心的话题（比如某个游戏）往往**不上热搜**。「订阅查询词」让她定期
全网搜索关注的话题，把结果作为"刷到"的素材——关注的是**话题本身**，
而不是某个账号，覆盖 B站/抖音/贴吧/新闻站等全平台。

配置方法：插件设置 →「订阅查询词」→ 填入查询词（如 `某游戏 社区 讨论`）
和 DeepSeek API 密钥即可，**无需部署任何额外服务**。

一次"刷到"大概长这样（示例）：

```
（搜索刷到的）
- 9月2日：官方公布新赛季更新预告，主题围绕全新地图与玩法
- 8月29日：体验服招募开启，玩家热议新武器与角色改动
- 近期：某角色将在下版本全面焕新，社区期待与观望并存
```

之后群里聊到相关话题，她就能自然接一句：
"哎我刷到新赛季要出新地图了，你们觉得咋样？"

- 每轮按轮换制挑一个查询词搜索（多条订阅词均匀覆盖）
- 结果自动去重、按「新鲜度阈值」过滤超龄内容
- 费用预估：半天一轮约每天几毛钱（视模型而定）
- 不填密钥则此功能静默关闭，其余功能不受影响

## 👥 进阶：聊天内容定制（可选）

不同群/私聊配不同的"关注面"——游戏群只收游戏资讯，
二次元群只收新番动态，格式：`群号或QQ号:关键词1,关键词2`

```
210589508:卡拉彼丘,游戏     # 这个群只注入卡拉彼丘圈的内容
123456789:二次元,新番       # 这个私聊只注入二次元相关
```

- 命中才注入，全不命中则该聊天本轮跳过（不硬塞）
- 未配置的聊天接收全部内容
- 前提：私聊需和她有过会话；群聊填群号即可（自动解析，无需查内部 ID）

## ⚙️ 配置说明

| 分组 | 说明 |
|---|---|
| 信息源 | 11 个榜单开关；API 实例地址可换成自部署的 60s 服务 |
| 过滤与兴趣 | 雷区关键词（最高优先级）；兴趣关键词（置顶加权）；严格模式；返回条数 |
| 订阅查询词 | 关注的话题（全网搜索）；DeepSeek 密钥（选填）；搜索深度 |
| 随机漫步 | 开关、模式（random/LLM）、间隔、采样池、QQ 群号/私聊 QQ 号（自动解析）、表达约束 |
| 聊天内容定制 | 按群/私聊配置关键词，只注入命中内容 |
| 调试 | 抓取诊断（显示原始/保留/兴趣命中/雷区拦截条数，用于验证过滤效果） |

配置支持热重载，改动即生效（后台任务读取最新配置）。

## 🧭 设计原则

- **素材归素材，人味归 Replyer**：工具只返回事实要点，绝不代表角色说话
- **雷区压倒一切**：过滤规则一旦配置，任何信息源、任何路径都不能越过
- **内容视角而非账号视角**：注入的是"刷到了什么"，不是"谁发了什么"
- **每群一面**：分群内容定制让她在不同圈子里有不同的话题面
- **安静失败**：任何信息源故障都不会影响聊天主线
- **零硬编码密钥、零第三方依赖**：纯标准库实现，降低安装与评审成本
